## What's New in 1.3.0

- Native Apple Silicon release for OpenEmuARM.
- Added Geolith support for `.neo` Neo Geo games.
- Added core selection persistence per game.
- Improved Arcade core selection, including MAME 2003 0.78.
- Added Cover Arts menus for consoles and games.
- Improved Game Scanner controls and ROM skip/stop handling.
- Added dark-mode application icon support.

## Bug Fixes

- Fixed duplicate core names.
- Fixed ROM import handling for unsupported or corrupted files.
- Fixed several Game Scanner layout issues.
- Removed deprecated MD5 API usage.
